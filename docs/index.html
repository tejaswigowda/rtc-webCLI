How this works, (with diagrams)
  • Audio, video and screen go directly between participants, encrypted (DTLS-SRTP).
  • The invite secret lives only after the # in the link; browsers never send it to a server.
  • Introductions go through public Nostr relays. They see a room hash and encrypted connection data.
  • A room exists only while someone is in it. Nothing is stored anywhere.
  • There is no host. Nobody can lock the room or remove anyone; anyone with the link is a peer.
